这是一个python库,用来封装各种第三方服务

要求:

- 功能修改需要通过单元测试验证
- 普通单元测试mock真实调用,使用`pytest`运行
- 手动运行单元测试,会真实调用外部服务,使用标记分组`pytest -m manual`运行
- 每个供应商服务都要提供可独立运行的本地手动测试，从根目录 `.env` 读取密钥，
  在 `.env.example` 和 README 中说明配置与命令；普通测试 mock 调用，默认不访问外部服务
- 单个文件代码不要超过300行,单个函数不要超过30行
- 使用python类型注释和代码注释,让代码方便阅读
- 不要过度设计：按需求提供最少的公共接口，同一功能保留一个调用入口，
  避免增加重复的便捷封装；第三方接口返回完整响应，由调用方按需解码或加工
- 常用配置应提供合理默认值，让常见场景只需传入必需参数；示例使用最简调用，
  调用方仅在需要调整行为时覆盖可选配置，降低使用门槛
- 音色等由调用方选择的业务参数必须显式传入，不设置默认值；
  腾讯云 TTS 的 `voice_type` 为必传参数，字幕、格式、语速、音量可使用默认值

Apifox:

- 默认项目 ID 为 `8929040`
- 使用 Apifox CLI 读取接口定义，按实际请求参数、鉴权方式和响应结构实现封装

目录组织:

- 以后新增供应商封装时，每个供应商必须在功能分类下使用独立子目录，
  格式为 `jwf_common_python/<分类>/<供应商>/`，例如 `jwf_common_python/tts/tencent/`
- 供应商的实现和内部辅助模块放在该子目录中，通过 `__init__.py` 导出公共接口
